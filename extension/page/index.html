Tab Topics

Rules suggest a topic when you save a tab — the suggestion is pre-selected in the picker and you confirm it (nothing files unattended). First matching rule wins. Drag rules to reorder priority. YouTube-channel rules match URLs that contain the handle, e.g. youtube.com/@handle/videos.

MatchValueTopicOn

The key enables YouTube video enrichment (publish date, channel name, channel id) for /watch and youtu.be links and channel-id/name rules. Create a free key at console.cloud.google.com (enable “YouTube Data API v3”). It stays on this machine and is only ever sent to googleapis.com; it is included in exports in masked form.

Keyboard shortcuts ↗

Import merges: new topics/entries/rules are added; on URL conflicts the local entry wins. Keyboard bindings live in Chrome itself and cannot be exported by the extension.

Cross-Device Sync (Google Drive)

Sync topics, queues, notes, rules, and settings across devices (including Android Chrome PWA) via your private Google Drive appDataFolder.

Tab Topics is an offline-first tab manager that saves tabs as persistent entries, organizes them into user-defined topics through a three-stage queue workflow (to_be_ordered → ordered → done), enriches YouTube videos with channel and publish-date metadata, and synchronizes state across devices using Google Drive (appDataFolder).
